  <h1>Taxonomy Webapp</h1>

  <h2>Overview</h2>
  <p>
    This web application is designed to manage images associated with species. It employs object-oriented programming and the Model-View-Controller (MVC) design pattern, using Spring Boot and Hibernate to handle persistence with a MySQL database.
  </p>

  <h2>Key Features</h2>
  <ul>
    <li>
      <strong>Image Management:</strong> Users can add, edit, delete, and view images along with metadata such as description, date, keywords, taxonomy, author, and license.
    </li>
    <li>
      <strong>Search Functionality:</strong> The application allows users to search images based on keywords, taxonomic classification, author, or owner.
    </li>
    <li>
      <strong>Related Data Handling:</strong> It also manages related entities like authors, owners, institutions, and various taxonomic levels.
    </li>
  </ul>

  <h2>Technologies Used</h2>
  <ul>
    <li>Spring Boot for rapid application development and dependency management.</li>
    <li>Hibernate for object-relational mapping with MySQL.</li>
    <li>HTML, CSS, and Bootstrap for building an intuitive and responsive user interface.</li>
  </ul>

  <h2>Conclusion</h2>
  <p>
    Overall, the project successfully delivers a comprehensive solution for managing species-related images, combining effective data handling with a user-friendly interface. This application demonstrates a practical use of modern web development frameworks and design patterns.
  </p>
